# travel-roadbook-generator（旅行攻略路书生成器）

一个用于生成旅行攻略路书的 Kimi Skill。

## 功能

根据出发地、日期、天数、人数、预算、已定住宿等信息，生成两份路书：

- **详细版**（Word + Markdown）：行程总览 → 逐日行程（含恶劣天气备选）→ 住宿信息或推荐 → 美食清单（带评分、防宰守则）→ 拍照机位推荐 → 穿衣推荐（含逐日天气预报）→ **门票预订清单（含具体预订日期与操作清单）** → 安全提醒 → 预算参考 → 关键提醒
- **极简版**（一页）：存手机随看随用

## 特点

- 风格：风险提示在前、独立判断、错误前提直接指出
- 票价/评分/天气等易变信息每次联网核实
- 住宿未定时按评分降序推荐（可指定价格上限或三档）
- 无住宿信息时自动带住宿推荐章节

## 安装

将 `travel-roadbook-generator.skill` 导入 Kimi（设置 → 个性化 → 技能 / 或拖入对话）。

## 使用示例

> 我们准备4号开始在秦皇岛及其周边自驾游玩，做一份两到三天的详细攻略，包括推荐美食和住宿。

| 文件 | 说明 |
